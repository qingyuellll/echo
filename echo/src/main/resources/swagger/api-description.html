前后端字段命名规范

实体 标准字段名 类型 说明
Show
演出		 name String 演出名称
images String 图片列表(JSON数组)
openTime String 开演时间
address String 详细地址
avgPrice Integer 平均票价(分)
sold Integer 已售数量
posterUrl - 已废弃
beginTime - 已废弃
Ticket
票种		 title String 票种标题
payValue Integer 支付金额(分)
actualValue Integer 实际价值(分)
soldCount Integer 已售数量(运行时)
isSeckill Boolean 是否秒杀票
seckillStock Integer 秒杀库存
remainingStock Integer 剩余库存
Order
订单		 id Long 订单ID(雪花算法)
ticketTitle String 票种标题(动态填充)
payValue Long 总价=quantity×单价(分)
verificationCode String 核销码(8位)
ticketName - 已废弃
orderNo - 已废弃
User
用户		 nickName String 用户昵称
phone String 手机号
name/username/nickname - 已废弃

重要提示：所有新代码必须使用标准字段，禁止使用已废弃字段！
